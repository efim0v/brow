# Brow — лимиты Claude Code в чёлке MacBook

[![CI](https://github.com/efim0v/brow/actions/workflows/ci.yml/badge.svg)](https://github.com/efim0v/brow/actions/workflows/ci.yml)
[![Latest release](https://img.shields.io/github/v/release/efim0v/brow)](https://github.com/efim0v/brow/releases/latest)
[![License: GPL-3.0](https://img.shields.io/github/license/efim0v/brow)](LICENSE)
[![Platform: macOS 26+ · Apple silicon](https://img.shields.io/badge/platform-macOS%2026%2B%20%C2%B7%20Apple%20silicon-lightgrey)](#требования)

Приложение для macOS, которое показывает **расход и лимиты всех ваших аккаунтов [Claude Code](https://claude.com/claude-code)** прямо в чёлке MacBook: 5-часовой лимит, недельный лимит и время сброса каждого из них. Войти в аккаунт можно в один клик — в отдельном профиле браузера, который принадлежит только этому аккаунту.

Brow для тех, у кого несколько подписок Claude и на каждой идёт своя работа с ИИ. С одного взгляда видно, какой аккаунт почти упёрся в лимит, где ещё есть запас и когда какой освободится. С одним аккаунтом Brow тоже работает: он сам находит `~/.claude` и показывает лимиты этого аккаунта.

**[Скачать Brow для macOS](https://github.com/efim0v/brow/releases/latest/download/Brow.zip)** или `brew install --cask efim0v/tap/brow` · macOS 26 или новее, Apple silicon · [подробнее об установке](#установка)

Во всех демо — выдуманные данные.

> **Приложение-компаньон: [Grove](https://github.com/efim0v/grove).** Grove выделяет каждой фиче проекта из нескольких репозиториев своё рабочее пространство для Claude Code и переносит сессию с одного аккаунта на другой. Brow подсказывает, у какого аккаунта есть запас, а Grove перебрасывает туда работу. Каждое приложение работает и само по себе, но задуманы они как пара.

## Возможности

- **Все аккаунты перед глазами.** Для каждого аккаунта: 5-часовой лимит, недельный лимит и недельный лимит отдельной модели, если он есть, — сколько процентов израсходовано и сколько времени осталось до сброса каждого.
- **Календарь сбросов.** Недельные сбросы и примерные даты продления подписок на сетке месяца: видно, какой аккаунт когда освободится.
- **Предупреждения о лимитах.** По умолчанию выключены. Если их включить, Brow присылает уведомление macOS, когда аккаунт израсходует 80 % и 95 % лимита, по одному на каждый порог до сброса.
- **Картинка с лимитами.** Кнопка внизу панели копирует картинку с лимитами ваших аккаунтов, чтобы вставить её в чат или пост. Аккаунты на ней пронумерованы, если не включить показ имён, а адресов почты там нет.
- **Команда запуска в буфер обмена.** Одна кнопка копирует команду, которая запускает Claude Code под этим аккаунтом.
- **Повторный вход в собственном браузере аккаунта.** У каждого аккаунта отдельный профиль браузера со своими cookie, историей и сохранёнными логинами, поэтому вход в один аккаунт никак не мешает другому. Вторая кнопка открывает этот профиль напрямую.
- **Новый аккаунт в один клик.** Brow создаёт папку аккаунта и запускает штатный вход Anthropic.
- **Свежие токены.** Токены простаивающих аккаунтов обновляются в фоне, так что цифры не устаревают. Аккаунт, в котором работает сессия Claude Code, Brow оставляет ей: такая сессия обновляет свой токен сама.

Для отдельных профилей браузера нужен Google Chrome, Chromium, Brave или Edge. Если их нет, ссылки открываются в браузере по умолчанию, без изоляции. Подробнее о частоте запросов, обновлении и вариантах расположения — в [`docs/brow.md`](docs/brow.md) (на английском).

## Что Brow делает на вашем Mac

Что стоит знать до запуска:

- **Brow читает токен авторизации Claude Code из связки ключей macOS (Keychain)** и использует его только для запросов к эндпоинтам Anthropic, которые отдают расход лимитов и данные профиля. Эти эндпоинты не входят в документированный публичный API и могут измениться. Токен не пишется на диск и не попадает в логи, а больше никуда ничего не отправляется. Если macOS не отдаёт токен аккаунта, у этого аккаунта появляется значок ключа; нажмите на него, и Brow запросит доступ у macOS.
- **Brow смотрит на запущенные процессы Claude Code**, когда токену аккаунта пора обновиться, чтобы никогда не обновлять токен, которым пользуется сессия. Он читает их командную строку и `CLAUDE_CONFIG_DIR`, больше ничего из их окружения, и время, когда аккаунт в последний раз сохранил запрос (`history.jsonl`). Зачем это нужно, написано в [частых вопросах](#обновляет-ли-brow-токен-которым-пользуется-claude-code).
- **Запасное обновление токена включено по умолчанию.** Если обычное обновление перестаёт работать, Brow выполняет крошечный запрос `claude -p`: он тратит немного лимита и запускает 5-часовое окно этого аккаунта. Отключается в Settings → Accounts; когда именно оно срабатывает, написано в [частых вопросах](#тратит-ли-brow-мои-лимиты).
- **Профиль браузера каждого аккаунта — отдельная папка** в `~/Library/Application Support/Brow/browser-profiles/`. Brow задаёт имя профиля и разрешает в нём сторонние cookie, чтобы работал вход.
- **Для входа открывается Терминал** с `claude auth login`; macOS один раз спросит, можно ли Brow управлять Терминалом.

Это независимый инструмент. Anthropic не имеет к нему отношения и не одобряла его.

## Требования

- macOS 26 или новее; готовая сборка — только для Apple silicon. Интерфейс вокруг чёлки рассчитан на MacBook, у которых она есть; на других дисплеях Brow показывает капсулу.
- Для сборки — Xcode со Swift 6.2.
- [Claude Code](https://claude.com/claude-code).
- Для отдельных профилей браузера — Chrome, Chromium, Brave или Edge.

## Установка

```sh
brew install --cask efim0v/tap/brow
```

Или скачайте **[Brow.zip](https://github.com/efim0v/brow/releases/latest/download/Brow.zip)** из [последнего релиза](https://github.com/efim0v/brow/releases/latest), распакуйте и перенесите `Brow.app` в `/Applications`.

Сборка подписана ad hoc и не нотаризована Apple, поэтому macOS заблокирует первый запуск, каким бы способом вы ни установили Brow. Откройте **Системные настройки → Конфиденциальность и безопасность**, найдите сообщение о Brow и нажмите **Все равно открыть** — или снимите атрибут карантина сами:

```sh
xattr -dr com.apple.quarantine /Applications/Brow.app
```

Если macOS не отдаёт Brow запись аккаунта из связки ключей, у аккаунта появляется оранжевый ключ, а в Settings → Accounts его токен помечен как *Keychain access needed*: нажмите на ключ или на **Grant Keychain access** там же и выберите **Разрешать всегда**. Сборка подписана ad hoc, поэтому после обновления на новую версию ключ может появиться снова.

Проверить загрузку можно по `SHA256SUMS.txt` из релиза: положите оба файла в одну папку и выполните `shasum -a 256 -c SHA256SUMS.txt`.

Значка в Dock у Brow нет: он живёт в чёлке, а настройки открываются кнопкой ⚙ на панели. Чтобы Brow запускался при входе в систему, включите **Launch at login** в Settings → General.

## Частые вопросы

### Тратит ли Brow мои лимиты?

Только через запасное обновление токена, и его можно отключить. Чтение лимитов — это запрос к эндпоинту Anthropic с данными о расходе, а не к модели. Токен простаивающего аккаунта Brow обновляет через `claude doctor`, который к модели тоже не обращается.

Запасное обновление включено по умолчанию. Когда токену аккаунта осталось жить 30 минут или меньше, а `claude doctor` его не продлил, Brow выполняет в этом аккаунте запрос `claude -p` в один ход на Haiku. Это тратит крошечную долю лимита аккаунта и запускает его 5-часовое окно. Brow не делает такой запрос, если Anthropic отклонила токен или `claude doctor` завершился по тайм-ауту либо не смог запуститься. Запрос уходит не чаще раза в 30 минут на аккаунт, а после трёх безрезультатных попыток подряд Brow перестаёт использовать его для этого аккаунта. Выключить запасное обновление можно в Settings → Accounts → **Allow `claude -p` fallback**.

### Обновляет ли Brow токен, которым пользуется Claude Code?

Нет. Claude Code продлевает токен с помощью refresh-токена, а тот меняется при каждом продлении: два продления почти одновременно могут оставить сессию с мёртвым токеном и просьбой выполнить `/login`. Поэтому Brow не трогает аккаунт, для папки которого запущен процесс `claude` (без `CLAUDE_CONFIG_DIR` это `~/.claude`), сколько бы эта сессия ни простаивала, и аккаунт, в котором за последние 15 минут вводили запрос. Сессия продлит токен сама. Пока этого не случилось, в Settings → Accounts у токена написано *in use by Claude Code, waiting for it to refresh*. Если токен уже истёк, панель показывает *Token in use by Claude Code*, а не предлагает войти заново; цифры вернутся, как только вы снова воспользуетесь этой сессией или закроете её.

### Откуда Brow берёт мой токен и уходит ли что-нибудь с моего Mac?

Из записи в связке ключей, которую Claude Code хранит для каждого аккаунта: `Claude Code-credentials` для `~/.claude` и `Claude Code-credentials-<hash>` для любой другой папки аккаунта. Brow читает её утилитой macOS `security`, а если не выходит — через Keychain API; со старыми установками Claude Code он вместо этого читает `.credentials.json` из папки аккаунта. Brow берёт только access-токен, а продлевать его оставляет самому Claude Code.

Собственные сетевые запросы Brow идут к двум эндпоинтам Anthropic и больше никуда: `api.anthropic.com/api/oauth/usage` — за цифрами и, примерно раз в день на аккаунт, `api.anthropic.com/api/oauth/profile` — за оценкой даты продления подписки для календаря. Ни аналитики, ни проверки обновлений в Brow нет. Команды `claude`, которые он запускает, ходят в сеть так же, как обычно ходит Claude Code, а профили браузера аккаунтов открывают claude.ai.

### На каких Mac работает Brow и где он находится на экране?

macOS 26 или новее; готовая сборка — только для Apple silicon. Brow находится вверху основного дисплея. Если на нём есть чёлка, оба показателя стоят по бокам от неё (по умолчанию) или в полосе под ней: Settings → General → **Ears**. А если на той же вкладке выключить **Show readouts next to the notch**, Brow ничего не рисует, пока курсор не дойдёт до чёлки. Когда у основного дисплея чёлки нет (например, это внешний монитор), Brow вместо этого показывает капсулу вверху по центру.

## Удаление

1. Если вы включали **Launch at login**, выключите его в Settings → General. Затем завершите Brow: нажмите ⌘Q, когда его окно настроек на переднем плане.
2. Удалите приложение: `brew uninstall --cask efim0v/tap/brow` или перенесите `Brow.app` из `/Applications` в корзину.
3. Закройте все окна браузера, которые Brow открыл для аккаунтов, и удалите файлы Brow: настройки, кеш с данными о лимитах и профили браузера аккаунтов (вместе с cookie и сохранёнными паролями), файл учёта частоты запросов, который Brow хранит в папке Grove, и то, что macOS сохранила для его сетевых запросов:

   ```sh
   rm -rf ~/Library/Application\ Support/Brow
   rm -f ~/Library/Application\ Support/Grove/oauth-usage-ledger.json
   rm -rf ~/Library/Caches/dev.artemefimov.brow ~/Library/HTTPStorages/dev.artemefimov.brow
   ```

4. Если вы добавляли в `~/.zshrc` строку Brow `export BROWSER=…`, удалите её.

Если вы сначала удалили приложение, а Brow по-прежнему виден в разделе Системные настройки → Основные → Объекты входа и расширения, удалите его там. Папки аккаунтов в `~/.claude-accounts` принадлежат Claude Code и без Brow работают как прежде.

## Как Brow и Grove работают вместе

Claude Code хранит каждый аккаунт в своей папке: `~/.claude` — аккаунт по умолчанию, `~/.claude-accounts/<name>` — остальные. Оба приложения читают эти папки, но напрямую друг с другом не общаются.

- **Аккаунты.** Brow создаёт папки аккаунтов, когда вы входите; Grove их подхватывает и может запустить любую сессию под любым из них.
- **Браузерный роутер.** Вместе с Brow идёт небольшой скрипт, который открывает ссылки в профиле браузера нужного аккаунта. Если Brow установлен, Grove передаёт этот скрипт каждой сессии Claude Code, которую запускает, поэтому запрос на вход из сессии попадает в нужный профиль.
- **Общий код.** Логика аккаунтов, учётных данных и расхода живёт в библиотеке `GroveCore` из Grove, от которой зависит этот пакет.

Полная картина, в том числе то, как аккаунты пользуются общими сессиями, — в [README Grove](https://github.com/efim0v/grove#how-grove-and-brow-fit-together) и в [`docs/grove-and-brow.md`](docs/grove-and-brow.md) (оба на английском).

## Сборка

```sh
git clone https://github.com/efim0v/brow.git
cd brow

swift test                 # fetches GroveCore from the Grove repository
Scripts/build-brow.sh      # -> dist/Brow.app
cp -R dist/Brow.app /Applications/
```

По умолчанию приложение подписывается ad hoc, и тогда macOS после каждой пересборки забывает разрешения на доступ к связке ключей и на автоматизацию. Чтобы они сохранялись, перед сборкой укажите в `GROVE_SIGN_IDENTITY` свой сертификат подписи `Apple Development: Name (TEAMID)`.
