# Brow — лимиты Claude Code в чёлке MacBook и рабочие пространства для параллельных сессий

[![CI](https://github.com/efim0v/brow/actions/workflows/ci.yml/badge.svg)](https://github.com/efim0v/brow/actions/workflows/ci.yml)
[![Latest release](https://img.shields.io/github/v/release/efim0v/brow)](https://github.com/efim0v/brow/releases/latest)
[![License: GPL-3.0](https://img.shields.io/github/license/efim0v/brow)](LICENSE)
[![Platform: macOS 26+ · Apple silicon](https://img.shields.io/badge/platform-macOS%2026%2B%20%C2%B7%20Apple%20silicon-lightgrey)](#требования)

Приложение для macOS для тех, кто работает в [Claude Code](https://claude.com/claude-code) сразу с нескольких аккаунтов. Оно делает две вещи:

- **Чёлка показывает расход и лимиты всех аккаунтов**: 5-часовой лимит, недельный лимит и время сброса каждого из них. Войти в аккаунт можно в один клик — в отдельном профиле браузера, который принадлежит только этому аккаунту.
- **Workspaces в строке меню запускает параллельные сессии Claude Code над продуктом, разбитым на несколько репозиториев**: на каждую фичу — своя папка с git worktree всех репозиториев на одной ветке, а сессия переезжает на тот аккаунт, у которого ещё есть запас.

На чёлку смотрят, в Workspaces работают. С одним аккаунтом Brow тоже работает: он сам находит `~/.claude` и показывает лимиты этого аккаунта, а Workspaces остаётся выключенным, пока вы его не включите.

**[Скачать Brow для macOS](https://github.com/efim0v/brow/releases/latest/download/Brow.zip)** или `brew install --cask efim0v/tap/brow` · macOS 26 или новее, Apple silicon · [подробнее об установке](#установка)

> **Пользовались Grove?** Grove теперь часть Brow. Brow находит ваши проекты и аккаунты Grove и запускает их в Workspaces; [вот что меняется](#если-вы-пользовались-grove).

### Одна ветка во всех репозиториях

Workspaces выделяет каждой фиче продукта из нескольких репозиториев свою папку, в которой лежит git worktree каждого репозитория на одной и той же ветке. Claude Code запускается в этой папке и видит весь продукт целиком; десять фич в работе — это десять папок, и ни одна сессия не может переключить ветку под другой.

## Возможности

В чёлке:

- **Все аккаунты перед глазами.** Для каждого аккаунта: 5-часовой лимит, недельный лимит и недельный лимит отдельной модели, если он есть, — сколько процентов израсходовано и сколько времени осталось до сброса каждого.
- **Календарь сбросов.** Недельные сбросы и примерные даты продления подписок на сетке месяца: видно, какой аккаунт когда освободится.
- **Предупреждения о лимитах.** По умолчанию выключены. Если их включить, Brow присылает уведомление macOS, когда аккаунт израсходует 80 % и 95 % лимита, по одному на каждый порог до сброса.
- **Глим, питомец, который ест лимиты.** Рядом с чёлкой живёт маленький зверёк и ест то, что тратят ваши аккаунты: когда растёт число 5-часового лимита, он откусывает кусочек. Если вы несколько часов за Mac, а Claude Code молчит, он проголодается; пока вас нет, голод не растёт. Когда 5-часовой лимит исчерпан, он засыпает сытым до сброса окна, а когда исчерпан недельный, впадает в спячку до недельного сброса. Включён по умолчанию; выключается в Настройках → General → **Show the pet**.
- **Картинка с лимитами.** Одна кнопка копирует картинку с лимитами ваших аккаунтов, чтобы вставить её в чат или пост. Аккаунты на ней пронумерованы, если не включить показ имён, а адресов почты там нет.
- **Команда запуска в буфер обмена.** Одна кнопка копирует команду, которая запускает Claude Code под этим аккаунтом.
- **Повторный вход — в собственном браузере аккаунта.** У каждого аккаунта отдельный профиль браузера со своими cookie, историей и сохранёнными входами, поэтому вход в один аккаунт никогда не мешает другому. Вторая кнопка открывает этот профиль напрямую.
- **Новый аккаунт в один клик.** Brow создаёт папку аккаунта и открывает собственный вход Anthropic.
- **Токены всегда свежие.** Токены простаивающих аккаунтов обновляются в фоне, поэтому цифры не устаревают. Аккаунт, которым пользуется сессия Claude Code, Brow оставляет этой сессии: она сама обновляет свой токен.

В Workspaces:

- **Рабочее пространство на каждую фичу.** Одна папка, в которой лежит git worktree каждого выбранного репозитория, все на одной ветке по вашему шаблону. Общие файлы вроде `CLAUDE.md` подкладываются сами, у каждого репозитория может быть свой хук после создания, а одно пространство можно ответвить от другого.
- **Сессии между аккаунтами.** **Resume as…** продолжает сессию под другим аккаунтом без копирования, **Migrate to…** копирует её целиком, даже в аккаунт, которым сейчас пользуются, а **Share** делает её видимой всем связанным аккаунтам. В каждом выборе аккаунта видны его лимиты, под тем именем, которое вы дали ему в Settings → Accounts.
- **Что сказала каждая сессия и кто с кем говорит.** Projects показывает каждую сессию по её состоянию и последнему обмену репликами — сначала то, что ждёт вас, — и предлагает папки, где работает Claude Code; **Agents** вживую рисует, как ваши сессии, субагенты и команды агентов переписываются.
- **Граф и статистика.** Граф коммитов каждого репозитория и число строк кода по всему проекту во времени.
- **Утилита командной строки `brow`** с командами `scan`, `workspaces`, `sessions`, `create`, `graph` и `doctor`, у каждой есть `--json`.

Для отдельных профилей браузера нужен Google Chrome, Chromium, Brave или Edge. Без них ссылки открываются в браузере по умолчанию, без разделения. Подробнее о чёлке — в [`docs/brow.md`](docs/brow.md), о Workspaces — в [`docs/workspaces.md`](docs/workspaces.md).

## Что Brow делает на вашем Mac

Стоит знать до запуска. Чёлка:

- **Brow читает токен входа Claude Code из Связки ключей macOS** и использует его только для запросов к эндпоинтам Anthropic с расходом и профилем. Эти эндпоинты — не документированный публичный API и могут измениться. Токен не пишется на диск и в логи, и больше никуда не отправляется. Если macOS не отдаёт токен аккаунта, у этого аккаунта появляется ключ; нажатие на него просит у macOS доступ.
- **Brow смотрит на запущенные процессы Claude Code**, когда токен аккаунта пора обновлять или его отклонили, чтобы никогда не обновлять токен, которым пользуется сессия. Он читает командную строку процессов `claude`, node, bun и deno, чтобы понять, какие из них — Claude Code, не берёт из их окружения ничего, кроме `CLAUDE_CONFIG_DIR`, и смотрит, когда каждый аккаунт последний раз сохранил промпт (`history.jsonl`). Зачем — в [FAQ](#обновляет-ли-brow-токен-которым-пользуется-claude-code).
- **Резервное обновление токена включено по умолчанию.** Если обычное обновление перестало работать, Brow отправляет крошечный запрос `claude -p`: он тратит немного лимита и запускает 5-часовое окно этого аккаунта. Выключается в Настройках → Accounts; когда именно он срабатывает, написано в [FAQ](#расходует-ли-brow-мои-лимиты).
- **Профиль браузера каждого аккаунта — отдельная папка** в `~/Library/Application Support/Brow/browser-profiles/`. Brow задаёт имя профиля и разрешает в нём сторонние cookie, чтобы вход работал.
- **Вход открывает Терминал** с `claude auth login`; macOS один раз спрашивает разрешение управлять Терминалом.
- **Brow отмечает первичную настройку Claude Code как пройденную** в папках аккаунтов, кроме `~/.claude`, перед тем как запустить там Claude Code: ставит `hasCompletedOnboarding` в `.claude.json` этой папки (и копирует вашу тему, если её там нет), чтобы сессия не открывала мастер первого запуска.
- **Когда питомец включён, Brow просит macOS сообщать ему о каждой записи в `history.jsonl` каждого аккаунта**, чтобы питомец оживлялся, когда вы запускаете Claude Code. Сам файл Brow не читает. Состояние питомца (его голод, последние показания, которые он видел, дни, когда он был сыт) хранится в `~/Library/Application Support/Brow/pet.json`.

Workspaces — только после того, как вы его включите (или Brow найдёт настройки Grove):

- **Он правит `settings.json` аккаунта, только если включить «Capture the status line»** для этого аккаунта в Настройках → Accounts (аккаунты, у которых Grove это уже делал, так и остаются). Он направляет `statusLine.command` на обёртку Brow, которая записывает модель, заполненность контекста и лимиты каждой сессии, а затем передаёт тот же ввод вашей прежней команде, поэтому ваша строка состояния продолжает работать. Выключение возвращает вашу команду. Claude Code запускает обёртку и при выключенном Workspaces, поэтому переключатель остаётся в Настройках → Accounts, пока вы его не выключите.
- **Общий доступ для аккаунта переносит его файлы сессий в `~/.claude`.** Всё, что было бы перезаписано, сначала сохраняется в `<аккаунт>/grove-backup/`.
- **Страховка транскриптов выключена, пока вы её не включите** (настройка Grove сохраняется). Когда она включена, Brow держит жёсткую ссылку на каждый транскрипт в `~/.claude/grove/transcripts/`. Пропавший транскрипт появляется в списке в Настройках → Workspaces и возвращается, только когда вы нажмёте **Restore**. Дольше, чем его хранит сам Claude Code, не хранится ничего: [`cleanupPeriodDays`](https://code.claude.com/docs/en/settings-reference#cleanupperioddays) — самый короткий срок из управляемых настроек вашей организации, настроек аккаунта и настроек проектов, в папках которых работали его сессии (для рабочего пространства, общего для нескольких аккаунтов, — самый короткий из сроков всех этих аккаунтов), — а транскрипт, до конца срока которого остаётся меньше дня, вернуть уже не предлагается. Не видит Brow только срок, переданный `claude` через `--settings`.
- **Он запускает git в ваших репозиториях**: `git worktree add` и ветку в каждом репозитории при создании пространства, а также хуки, которые вы настроили. Сам он никогда не удаляет worktree и ветки.
- **Он управляет cmux**: через сокет cmux — с паролем из `~/.config/cmux/cmux.json`, если cmux его требует, — и через AppleScript, на что macOS один раз спросит разрешение.
- **`--dangerously-skip-permissions` — только по вашей просьбе**, для проекта или для одного запуска.
- **Он смотрит, в каких папках работает Claude Code и чем закончился разговор в каждой сессии.** Когда открывается панель и каждые несколько секунд, пока виден список Projects, Brow читает записи сессий, которые Claude Code ведёт в папке `sessions/` каждого аккаунта, и смотрит на запущенные процессы `claude`: их командную строку, рабочую папку и из окружения только `CLAUDE_CONFIG_DIR`. Так у каждой сессии появляется состояние, а папки, где работает Claude, но которые ещё не проекты, предлагаются добавить. Для превью он читает последние 64 КБ транскрипта сессии: ваш последний промпт и последнюю строку Claude. Настройки → Workspaces → **Show message previews** выключает превью. Ничего из этого никуда не записывается и не отправляется.
- **Вкладка Agents читает то, что Claude Code пишет, когда агенты переписываются**, — только пока панель открыта и полминуты после: транскрипты, записанные за последние полчаса, почтовые ящики команд агентов в `teams/` каждого аккаунта и записи сессий. От сообщения она хранит первую строку, в памяти, не дольше часа. Она никогда не подключается к сокету сессии, не открывает ключи входящих рядом с записями и не вмешивается в разговор.

Как всё это отменить, описано в разделе [Удаление](#удаление).

Это независимый инструмент, не связанный с Anthropic и не одобренный ею.

## Требования

- macOS 26 или новее; готовая сборка — только для Apple silicon. Раскладка рассчитана на MacBook с чёлкой; на других экранах Brow показывает «пилюлю».
- Xcode со Swift 6.4 или новее — для сборки (Swift 6.2 не собирает BrowKit).
- [Claude Code](https://claude.com/claude-code).
- Для отдельных профилей браузера: Chrome, Chromium, Brave или Edge.
- Для Workspaces: git и терминал для сессий — [cmux](https://cmux.dev) (рекомендуется) или Terminal.app ([в чём разница](docs/workspaces.md#cmux-or-terminalapp)). Возобновлению под другим аккаунтом и страховке транскриптов нужен аккаунт, вошедший в стандартной папке `~/.claude`.

## Установка

```sh
brew install --cask efim0v/tap/brow     # приложение
brew install efim0v/tap/brow-cli        # утилита командной строки brow, если нужна
```

Или скачайте **[Brow.zip](https://github.com/efim0v/brow/releases/latest/download/Brow.zip)** из [последнего релиза](https://github.com/efim0v/brow/releases/latest), распакуйте и перенесите `Brow.app` в `/Applications`. В релизе есть ещё `brow-cli.zip` — утилита командной строки (с `grove` в качестве второго имени) — и `SHA256SUMS.txt`: положите скачанное в одну папку и выполните `shasum -a 256 -c --ignore-missing SHA256SUMS.txt`.

Сборка подписана ad hoc и не нотаризована Apple, поэтому при первом запуске macOS её заблокирует, как бы вы её ни ставили. Откройте **Системные настройки → Конфиденциальность и безопасность**, найдите сообщение о Brow и нажмите **Всё равно открыть** — или снимите флаг карантина сами:

```sh
xattr -dr com.apple.quarantine /Applications/Brow.app
```

Утилита `brow` из `brow-cli.zip` получает тот же флаг, если скачать её в браузере: `xattr -d com.apple.quarantine brow`.

Если macOS не отдаёт Brow элемент Связки ключей какого-то аккаунта, у этого аккаунта появляется оранжевый ключ, а в Настройках → Accounts его токен помечен как *Keychain access needed*: нажмите на ключ или **Grant Keychain access** и выберите **Всегда разрешать**. Поскольку сборка подписана ad hoc, ключ может вернуться после обновления на новую сборку.

У Brow нет значка в Dock: он живёт в чёлке, а его настройки открываются через ⚙ на панели. Чтобы Brow запускался при входе в систему, включите **Launch at login** в Настройках → General. Чтобы начать пользоваться Workspaces, откройте **Настройки → Workspaces** или нажмите кнопку со стопкой квадратов на панели чёлки и выберите **Add project…**.

## Если вы пользовались Grove

С версии 0.4.0 движок Workspaces из Grove — часть Brow, вместе со своей историей; [репозиторий grove](https://github.com/efim0v/grove) остаётся, только для чтения, для старых сборок.

- **Ваша настройка переезжает нетронутой.** Brow находит `~/Library/Application Support/Grove/config.json` и включает Workspaces с вашими проектами, аккаунтами, перехваченными строками состояния и настройками страховки. Ничего не переносится: обёртки строки состояния остаются в `Grove/bin`, куда указывает `settings.json` каждого такого аккаунта.
- **Чёлка читает каждый аккаунт, в том числе аккаунты Workspaces.** Grove не обращался ни к Связке ключей, ни к Anthropic; чёлка обращается — для каждого аккаунта, который находит, включая те, что знает Workspaces. Она читает вход аккаунта из Связки ключей (если macOS не отдаёт элемент, у аккаунта появляется оранжевый ключ: нажмите на него и выберите **Всегда разрешать**), запрашивает его лимиты у эндпоинта расхода Anthropic и обновляет токены простаивающих аккаунтов через `claude doctor`. Если это не помогло, она отправляет однократный запрос `claude -p`: он тратит немного лимита этого аккаунта и запускает его 5-часовое окно. Выключается в Настройках → Accounts → **Allow `claude -p` fallback**. Остальное — в разделе [Что Brow делает на вашем Mac](#что-brow-делает-на-вашем-mac).
- **Сначала закройте Grove.app.** Пока он работает, Workspaces ждёт и предлагает **Quit Grove**, чтобы два приложения не писали в одни и те же файлы. Затем удалите `Grove.app` (или `brew uninstall --cask grove`), а если вы добавляли его в объекты входа, уберите его оттуда и включите **Launch at login** в Brow.
- **Что куда переехало.** Дерево в строке меню теперь знак Brow — чёлка с двумя точками. Экран настроек панели переехал в **Настройки → Workspaces**; добавление аккаунтов, общий доступ и перехват строки состояния — в **Настройки → Accounts**, где новый аккаунт добавляется кнопкой Brow **Sign in…**. Настройки отдельных проектов остались в панели.
- **Утилита командной строки теперь `brow`.** `brow-cli.zip` ставит `brow` и `grove` как второе имя, так что ваши скрипты работают без изменений. Если утилита Grove стоит у вас через Homebrew, выполните `brew uninstall grove-cli` перед `brew install efim0v/tap/brow-cli`: обе ставят `grove`.
- **Страховка транскриптов больше ничего не возвращает сама.** Раньше она сама возвращала любой транскрипт младше 90 дней, в том числе удалённые собственной очисткой Claude Code. Теперь она ничего не хранит дольше срока хранения Claude Code, а пропавшие транскрипты показывает в Настройках → Workspaces с кнопкой **Restore**. Поэтому транскрипты старше `cleanupPeriodDays` (30 дней, если вы не задали другой срок), которые Grove раз за разом возвращал, уйдут при следующей очистке Claude Code, а страховка удалит свои копии. Чтобы сохранить старые сессии, увеличьте `cleanupPeriodDays` в `settings.json` каждого аккаунта до перехода.

## FAQ

### Расходует ли Brow мои лимиты?

Только через резервное обновление токена, и его можно выключить. Чтение лимитов — это запрос к эндпоинту расхода Anthropic, а не к модели, а токен простаивающего аккаунта поддерживается свежим через `claude doctor`, который не обращается к модели.

Резервное обновление включено по умолчанию. Когда у токена аккаунта остаётся 30 минут или меньше, а `claude doctor` его не продлил, Brow отправляет в этом аккаунте однократный запрос `claude -p` к Haiku. Он тратит крошечную долю лимита аккаунта и запускает его 5-часовое окно. Brow пропускает его, если Anthropic отклонил токен или `claude doctor` не уложился во время или не смог запуститься, запускает его не чаще раза в 30 минут на аккаунт и перестаёт использовать для аккаунта после трёх безуспешных попыток подряд. Выключается в Настройках → Accounts → **Allow `claude -p` fallback**.

### Обновляет ли Brow токен, которым пользуется Claude Code?

Нет. Claude Code продлевает токен с помощью refresh-токена, который меняется при каждом продлении, поэтому два продления примерно в одно время могут оставить сессию с мёртвым токеном и просьбой выполнить `/login`. Brow не трогает аккаунт, если для его папки запущен процесс `claude` (без `CLAUDE_CONFIG_DIR` — это `~/.claude`), сколько бы эта сессия ни простаивала, и аккаунт, в котором за последние 15 минут вводили промпт. Сессия сама продлит токен. Пока она этого не сделала, Настройки → Accounts показывают токен как *in use by Claude Code, waiting for it to refresh*. Если токен уже истёк, панель показывает *Token in use by Claude Code* вместо просьбы войти, а цифры вернутся, как только вы снова воспользуетесь этой сессией или закроете её.

### Откуда Brow читает мой токен и уходит ли что-нибудь с моего Mac?

Из элемента Связки ключей, который Claude Code хранит для каждого аккаунта: `Claude Code-credentials` для `~/.claude`, `Claude Code-credentials-<хеш>` для любой другой папки аккаунта. Brow читает его системной утилитой `security`, а если не вышло — через API Связки ключей; со старыми версиями Claude Code он читает `.credentials.json` в папке аккаунта. Он использует только токен доступа и оставляет его продление Claude Code.

Собственные сетевые запросы Brow идут к двум эндпоинтам Anthropic и больше никуда: `api.anthropic.com/api/oauth/usage` за цифрами и примерно раз в день на аккаунт `api.anthropic.com/api/oauth/profile` за оценкой продления для календаря. У Brow нет аналитики и проверки обновлений. Workspaces сам ничего не запрашивает по сети; запускаемые им команды `claude` и `git` устанавливают свои обычные соединения, а профили браузера аккаунтов открывают claude.ai.

### На каких Mac он работает и где располагается?

macOS 26 или новее; готовая сборка — только для Apple silicon. Brow располагается вверху основного экрана. Если у этого экрана есть чёлка, два числа стоят по бокам от неё (по умолчанию) или в полосе под ней: Настройки → General → **Ears**. Если выключить **Show readouts next to the notch** на той же вкладке, ничего не рисуется, пока курсор не дойдёт до самой чёлки. Если у основного экрана чёлки нет, например у внешнего монитора, Brow показывает вверху по центру «пилюлю», а с выключенными числами — ничего, пока курсор не дойдёт до верха экрана по центру. Если Brow нужен вам только ради Workspaces, выключите **Show Brow in the notch**, и вверху экрана он не будет рисовать ничего; предупреждения о лимитах при этом приходят.

### Тратит ли питомец батарею?

Он рисуется, только пока экран включён и вы за Mac: 30 кадров в секунду в покое, от 60 до 120 на секунду-другую, пока он ест или двигается, и ни одного, когда экран заблокирован или спит, когда вас нет уже десять минут или когда питомец выключен. Он учитывает настройку «Уменьшение движения» (Reduce Motion).

### Я не вижу значка Brow в строке меню.

На MacBook с чёлкой macOS прячет значки строки меню, которые не помещаются рядом с ней. Workspaces всё равно открывается кнопкой со стопкой квадратов на панели чёлки, пунктом **Show Workspaces** в меню Brow и повторным открытием Brow из Finder или Spotlight. Настройки → General → **Show Workspaces in the menu bar** убирает значок совсем.

### Почему не встроенные worktree Claude Code?

`claude --worktree` даёт одной сессии worktree репозитория, в котором вы его запустили, — для одного репозитория этого может хватить. Workspaces — для продукта из нескольких репозиториев: одна ветка во всех них в одной папке, свои имена веток и точки старта, файлы и хуки при создании и сессии, которые переезжают между аккаунтами. [Подробный ответ](docs/workspaces.md#why-not-claude-codes-built-in-worktrees).

## Удаление

1. **Если вы пользовались Workspaces, сначала верните каждому аккаунту его строку состояния** — обёртки лежат в папке Grove, которую шаг 4 удаляет. В Настройках → Accounts выключите **Capture the status line** у каждого аккаунта, где он есть; переключатель там и при включённом, и при выключенном Workspaces, а если Grove ещё запущен, сначала закройте его. Затем проверьте, что ни один `settings.json` больше не указывает на обёртку:

   ```sh
   find ~/.claude ~/.claude-accounts -maxdepth 2 -name settings.json -exec grep -l grove-statusline {} +
   ```

   Для каждого найденного файла откройте скрипт, который назван в его `statusLine.command`: строка `GROVE_ORIG` в нём хранит команду, которая была у вас раньше. Верните эту команду или удалите ключ `statusLine`, если `GROVE_ORIG` пуст.
2. Если вы включали **Launch at login**, выключите его в Настройках → General. Затем закройте Brow сочетанием ⌘Q, пока впереди его окно настроек, или кнопкой **Quit Brow** на панели Workspaces.
3. Удалите приложение: `brew uninstall --cask efim0v/tap/brow` и `brew uninstall efim0v/tap/brow-cli` либо перенесите `Brow.app` и утилиту `brow` в Корзину.
4. Закройте окна браузера, которые Brow открывал для аккаунтов, затем удалите файлы Brow: его настройки, сохранённые показания, состояние питомца и профили браузера аккаунтов (вместе с cookie и сохранёнными паролями), папку Workspaces (его настройки, скрипты-обёртки, статистику кода и файл с темпом запросов) и то, что macOS сохранила для сетевых запросов Brow:

   ```sh
   rm -rf ~/Library/Application\ Support/Brow
   rm -rf ~/Library/Application\ Support/Grove
   rm -rf ~/Library/Caches/dev.artemefimov.brow ~/Library/HTTPStorages/dev.artemefimov.brow
   ```

   Если вы пользовались Grove, `defaults delete dev.artemefimov.grove3` удалит и его настройки.

5. Если вы пользовались Workspaces, удалите то, что он хранил в папках аккаунтов: `~/.claude/grove/` (страховка транскриптов и перехваты строки состояния основного аккаунта; сами транскрипты в `projects/` каждого аккаунта остаются) и `grove/` в каждой другой папке аккаунта. Прежде чем удалять папку `grove-backup/` — то, что отложил общий доступ, — просмотрите её. У аккаунта с общим доступом `file-history`, `tasks` и `session-env`, а также `projects/<пространство>` для каждого общего пространства — символические ссылки на `~/.claude`, и они продолжают работать; подробнее в [`docs/workspaces.md`](docs/workspaces.md#how-accounts-share-sessions).
6. Если вы добавляли строку Brow `export BROWSER=…` в `~/.zshrc`, удалите её.

Если вы сначала удалили приложение, а Brow всё ещё есть в Системных настройках → Основные → Объекты входа и расширения, уберите его там. Папки аккаунтов в `~/.claude-accounts` принадлежат Claude Code и работают без Brow. Рабочие пространства — это обычные git worktree и ветки в ваших репозиториях, поэтому они остаются: чтобы убрать пространство, выполните `git worktree remove` для каждого его worktree, затем удалите его папку.

## Сборка

```sh
git clone https://github.com/efim0v/brow.git
cd brow

Scripts/test-in-empty-home.sh   # все тесты, с домашней папкой, подменённой пустой
Scripts/build-brow.sh           # -> dist/Brow.app и dist/brow
cp -R dist/Brow.app /Applications/
```

По умолчанию приложение подписывается ad hoc. Тогда macOS забывает разрешения Связки ключей и автоматизации после каждой пересборки; чтобы они сохранялись, перед сборкой задайте в `BROW_SIGN_IDENTITY` свой сертификат `Apple Development: Name (TEAMID)`.

## Разработка

- `Scripts/test-in-empty-home.sh` и `Scripts/test-in-empty-home.sh -c release` должны оставаться зелёными; `Scripts/check-warnings.sh` не должен находить новых предупреждений.
- `swift run BrowApp --snapshot /tmp/brow-snap` рисует экраны Workspaces в PNG, не запуская приложение; см. [`docs/snapshot-testing.md`](docs/snapshot-testing.md).
- Скриншоты в этом README пересоздаются командой
  `DEMO_SCREENSHOTS_DIR="$PWD/docs/screenshots" swift test --filter DemoScreenshotTests`.
- Константы контура чёлки лежат в `Sources/BrowKit/Panel/NotchGeometry.swift`; их подгоняют на глаз по реальной рамке экрана.
